# Manajemen Item & Jasa (Price List)

Fitur bagi admin untuk menambah, menyunting, dan menonaktifkan paket harga yang ditampilkan di Landing Page bagian Pricelist.

## Spesifikasi

### Tujuan
Admin dapat mengelola daftar paket jasa yang ditampilkan di bagian Pricelist pada Landing Page pelanggan, termasuk menambah, menyunting, dan menonaktifkan paket.

### Selesai bila
- Admin melihat tabel daftar paket dengan kolom: nama paket, harga, jumlah revisi, dan status aktif/nonaktif.
- Admin dapat menambah paket baru dengan mengisi: nama, harga (Rp), deskripsi singkat, jumlah revisi, dan catatan penting (opsional).
- Admin dapat menyunting seluruh data paket yang sudah ada.
- Admin dapat menonaktifkan paket (tidak tampil di Landing Page) tanpa menghapus data.
- Perubahan yang dilakukan langsung tercermin di halaman Pricelist tanpa perlu reload manual.
